# MVP 인수 테스트 시나리오

## 1. 목적

개발 완료를 주관적인 판단이 아니라 반복 가능한 테스트 결과로 확인한다.

---

# 2. 룸 테스트

## AT-ROOM-001 방 생성

- 사전 조건: 서버 실행
- 절차:
  1. 클라이언트 A에서 방 생성
  2. 방 코드 확인
- 기대 결과:
  - 방 코드가 표시된다.
  - A가 왼쪽 또는 첫 번째 슬롯에 배정된다.
  - 룸 상태가 CREATED다.

## AT-ROOM-002 정상 참가

- 사전 조건: A가 방 생성
- 절차:
  1. B가 방 코드 입력
  2. 참가 버튼 클릭
- 기대 결과:
  - B가 두 번째 슬롯에 배정된다.
  - 두 화면에 플레이어 2명이 표시된다.
  - 룸 상태가 WAITING이다.

## AT-ROOM-003 잘못된 코드

- 절차: 존재하지 않는 코드 입력
- 기대 결과:
  - 참가하지 않는다.
  - 오류 메시지가 표시된다.

## AT-ROOM-004 정원 초과

- 사전 조건: 두 명 입장 완료
- 절차: C가 같은 방 참가 시도
- 기대 결과:
  - 참가가 거부된다.

# 4. 이동 테스트

## AT-MOVE-001 개별 이동

- 절차:
  1. A만 전진
  2. B 입력 없음
- 기대 결과:
  - A가 이동한다.
  - B는 링크 규칙에 따라 제한적으로 영향을 받는다.
  - 최대 거리를 넘지 않는다.

## AT-MOVE-002 같은 방향 이동

- 절차: A와 B가 같은 방향 입력
- 기대 결과:
  - 반대 방향 입력보다 팀 중심 이동 속도가 높다.
  - 캐릭터가 심하게 흔들리지 않는다.

## AT-MOVE-003 반대 방향 이동

- 절차: A와 B가 정확히 반대 방향으로 10초 입력
- 기대 결과:
  - 링크 최대 거리를 넘지 않는다.
  - 캐릭터가 순간이동하지 않는다.
  - 시뮬레이션이 멈추지 않는다.

## AT-MOVE-004 벽 모서리

- 절차: 연결된 상태로 벽 모서리에 접근
- 기대 결과:
  - 벽을 통과하지 않는다.
  - 5초 이상 무한 진동하지 않는다.
  - 반대 방향 입력으로 빠져나올 수 있다.

- 기대 결과:
  - 오른팔 히트박스만 활성화된다.

## AT-COMBAT-003 중복 적중 방지

## AT-COMBAT-007 방어 후방

- 기대 결과:
  - 방어 감소가 적용되지 않거나 크게 감소한다.

# 7. 체력과 다운 테스트

## AT-HP-001 체력 감소

- 기대 결과:
  - 피격 대상 체력만 감소
  - 두 클라이언트의 값 일치

## AT-HP-002 한 명 다운

- 절차: 아군 한 명 체력 0
- 기대 결과:
  - 해당 파이터 DOWN
  - 이동과 공격 불가
  - 경기는 계속됨
  - 링크는 DOWN_DRAG

## AT-HP-003 다운 팀원 드래그

- 절차: 생존 파이터 이동
- 기대 결과:
  - 다운 파이터가 따라온다.
  - 벽 통과 없음
  - 생존 파이터 이동 속도 감소

## AT-HP-004 두 명 다운

- 기대 결과:
  - 즉시 패배 판정
  - 입력 비활성
  - 결과 화면 표시

## AT-HP-005 동시 다운

- 절차: 같은 서버 틱에서 양 팀 마지막 파이터 체력 0
- 기대 결과:
  - 무승부

# 10. 네트워크 테스트

- 기대 결과:

## AT-NET-002 100ms 지연

- 조건: 개발 도구로 지연 적용

  - 남은 플레이어에게 연결 종료 결과 표시
