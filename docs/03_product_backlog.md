# MVP 제품 백로그

## 1. 우선순위 기준

| 우선순위 | 의미 |
|---|---|
| P0 | 핵심 재미 및 진행에 필수 |
| P1 | 한 경기 완성에 필수 |
| P2 | 온라인 MVP에 필수 |
| P3 | 완성도 향상 |
| P4 | 이후 확장 |

난이도 표기:

- S: 반나절 이내
- M: 1일 내외
- L: 2~3일
- XL: 분해가 필요한 작업

# 2. Epic A — 프로젝트 기반 구축

## US-A01 저장소 및 모노레포 구성

- 우선순위: P0
- 난이도: S
- 사용자 스토리: 개발자로서 클라이언트, 서버, 공용 타입을 한 저장소에서 일관되게 관리하고 싶다.
- 작업:
  - client, server, shared 디렉터리
  - TypeScript 설정
  - ESLint/Prettier
  - 환경변수 예시
  - 기본 실행 스크립트
- 완료 조건:
  - 한 명령으로 클라이언트와 서버를 각각 실행할 수 있다.
  - shared 타입을 양쪽에서 참조할 수 있다.

## US-A02 공용 상수와 타입 정의

- 우선순위: P0
- 난이도: S
- 작업:
  - GameState
  - FighterState
  - LinkState
  - RoomState
  - 입력 메시지 타입
  - 상태 스냅샷 타입
- 완료 조건:
  - 클라이언트와 서버에 중복 enum이 없다.

## US-A03 개발 디버그 패널

- 우선순위: P1
- 난이도: M
- 표시:
  - FPS
  - 핑
  - 캐릭터 상태
  - 링크 거리
  - 링크 상태
  - 체력
- 완료 조건:
  - 개발 모드에서 토글할 수 있다.
