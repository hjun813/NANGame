# 개발 위험 관리대장

## 1. 평가 기준

발생 가능성:

- 낮음
- 중간
- 높음

영향도:

- 낮음: 일부 품질 저하
- 중간: 기능 지연 또는 우회 필요
- 높음: 핵심 재미 또는 MVP 완성 실패

# 2. 위험 목록

## R-001 링크 이동 떨림

- 발생 가능성: 높음
- 영향도: 높음
- 증상:
  - 최대 거리에서 두 캐릭터가 반복적으로 튐
  - 벽 근처에서 진동
- 원인:
  - 물리 엔진 반발과 수동 위치 보정 충돌
- 예방:
  - 고정 타임스텝
  - Joint 의존 최소화
  - 예상 이동 단계에서 보정
- 대응:
  - 캐릭터 간 직접 충돌 완화
  - 최대 보정량 제한
  - 벽 모서리 탈출 규칙
- 조기 경고:
  - 10초 반대 방향 입력에서 위치 변화가 불안정

## R-002 링크 규칙이 재미보다 답답함을 만듦

- 가능성: 높음
- 영향도: 높음
- 예방:
  - 같은 방향 이동 보상
  - 장력 시각화
  - 손잡기 탈출 수단
- 대응:
  - 거리, 감속, 회전 보정 조절
  - 이동 입력 평균 방식 변경
- 판단 기준:
  - 테스트 팀 절반 이상이 연결 제거를 요구

## R-003 온라인 지연으로 조작감 저하

- 가능성: 중간
- 영향도: 높음
- 예방:
  - 서버 틱과 상태 전송 분리
  - 원격 보간
  - 입력 메시지 최소화
- 대응:
  - 제한적 로컬 예측
  - 시각 오브젝트와 서버 콜라이더 분리
- 조기 경고:
  - 100ms에서 입력이 즉시 불쾌하게 느껴짐

## R-004 공격 판정 불일치

- 가능성: 중간
- 영향도: 높음
- 예방:
  - 서버 판정
  - 공격 ID와 적중 대상 집합
- 대응:
  - 히트박스 단순화
  - 판정 틱 확대
- 조기 경고:
  - 두 클라이언트 체력 값 불일치

## R-005 다운 캐릭터 끼임

- 가능성: 높음
- 영향도: 높음
- 예방:
  - 완전한 래그돌 제외
  - 다운 충돌체 축소
  - 최대 후행 거리
- 대응:
  - 안전 위치 보정
  - 일정 시간 정체 시 드래그 우선 처리

## R-006 AI 개발 범위 증가

- 가능성: 중간
- 영향도: 중간
- 예방:
  - 상태 머신 최소화

- 대응:
  - AI 두 명을 하나의 팀 컨트롤러가 관리
  - 방어 상태 제거
- 범위 축소 순서:
  1. AI 손잡기 제거
  2. AI 방어 제거
  3. AI 타깃 전환 단순화

## R-010 일정 부족

- 가능성: 높음
- 영향도: 높음
- 예방:
  - P0, P1, P2 범위 분리
  - 매일 플레이 가능한 빌드 유지
- 기능 제거 순서:

  2. 카메라 벽 충돌

  4. 재경기

## R-013 네트워크 좌표 보정이 클라이언트 물리를 우회

- 가능성: 높음
- 영향도: 높음
- 증상:
  - 서버 스냅샷 적용 후 플레이어가 적 콜라이더를 통과한다.
  - 같은 룸인데도 초기화 후 탭별 소유 캐릭터 위치가 다르다.
  - 스냅샷 처리 중 예외가 발생해 HP·상태 갱신까지 멈춘다.
- 원인:
  - Rapier가 없는 서버 좌표를 클라이언트 물리 객체에 매 tick teleport한다.
  - 평상시 소유권 규칙과 경기 초기화 규칙을 같은 방식으로 처리한다.
  - 서버와 클라이언트의 스냅샷 필드 배포 시점이 다르다.
- 예방:
  - 평상시에는 소유 캐릭터의 로컬 Rapier 결과를 보존하고 원격 캐릭터만 동기화한다.
  - 초기화는 별도 `resetRevision`으로 식별한다.
  - 새 스냅샷 필드는 전환 기간에 optional로 읽고 존재 여부를 확인한다.
  - HUD에 실제 전투 룸 ID와 배정 파이터를 노출한다.
- 대응:
  - 서버 물리 도입 전에는 session-slot, sequence, 좌표 범위, 최대 이동량을 검증한다.
  - 서버 물리 도입 후 입력 전송과 서버 고정 tick 계산으로 교체한다.
- 조기 경고:
  - 두 탭의 `Combat room` ID는 같지만 Link dist 또는 초기 위치가 지속적으로 다르다.
  - Rapier collision 수치가 0으로 유지되면서 콜라이더를 통과한다.
  - 콘솔에 스냅샷 position 관련 런타임 오류가 발생한다.
- 관련 기록: ADR-008, NET-SYNC-001

# 4. 개발 중단 기준

다음 중 하나가 발생하면 새 기능 개발을 중단하고 위험 해결을 우선한다.

- 플레이 가능한 빌드가 하루 이상 유지되지 않음
- 링크 이동 때문에 기본 전투 테스트가 불가능함
- 두 클라이언트의 체력 또는 승패가 반복적으로 불일치함
- 다운 캐릭터 때문에 경기 완료율이 70% 미만임
- 배포 환경에서 두 명 접속이 불가능함
